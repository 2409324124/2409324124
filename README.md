## Seq2Seq 项目亮点

这个项目是我目前最完整的一次深度学习复现实践：

- 从零实现 Encoder、Decoder、Bahdanau Attention、teacher forcing、梯度裁剪、Beam Search 和 sacreBLEU 评估。
- 在 Multi30k 德语到英语翻译任务上完成完整训练流程，测试集 BLEU 达到 **56.3**。
- 提供 Loss 曲线、注意力热图和可交互翻译 Demo。
